## 一、调试台收进设置

底部 tab 从 5 个减到 4 个：**监看 / AI 调色 / 相册 / 预设库**。

调试台对日常拍摄是纯噪声——它只在协议对不上、要看 PTP Hex 日志时才用得到。占着一个
tab 的位置，等于把相册、预设库挤窄。现在它挪到 **设置 → 高级 → USB 调试台**，
点开是整屏覆盖层（比原来在 tab 里视野更大），左上角返回箭头退出。

顶栏右上角新增齿轮图标，设置从这里进。

## 二、新增设置项（9 项）

### 日常使用

| 设置 | 选项 | 说明 |
|---|---|---|
| 相册读取张数 | 50 · 最快 / **100 · 推荐** / 200 · 较慢 | 只读最近 N 张。全卡遍历要给每个文件发一次 `GetObjectInfo`，越多越慢 |
| 取景帧率 | 流畅 16fps / **标准 6fps** / 省电 3fps / 极省 2fps | 取景是预览不是录制，等光时调低能明显省电 |
| 默认目标槽位 | C1~C9 九宫格 | 每次打开 App 时预选的槽位，刷入时仍可临时改 |
| 监看页常亮 | 开 / 关（默认**开**） | 进监看页不让屏幕自己灭，拍延时/等光很有用。离开 tab 自动撤销，不会影响其它页 |
| 拍完自动存手机 | 开 / 关（默认**关**） | 开：每次拍完自动写进系统相册 `Pictures/ZCloudAI`。关：只留 App 里手动点保存 |

### 刷入机身

| 设置 | 默认 | 说明 |
|---|---|---|
| 写入前先备份原样模板 | **开** | 先读回该槽位原始 614 字节做模板，只覆盖名称与曲线。关掉更快，但写坏不好还原 |
| 写入后回读校验 | **开** | 写完立刻读回名称比对。多一次往返，但能当场发现「以为写进去了其实没有」 |

### 日志

| 设置 | 默认 | 说明 |
|---|---|---|
| 持续写入日志文件 | **开** | 存在 `Android/data/com.zcloud.ai/files/logs/`。手机只有一个 USB-C 口，接电脑就没法接相机，必须 App 自己留证据 |
| 日志包含 Hex 字节 | **开** | 关掉后每条形如 `[21:58:46.613] RX tx=34 CMD 0x90CC（614B，未 dump）`。一帧取景 20KB、dump 出来几百行——之前日志动辄 5MB 主要就是这个 |

「导出日志快照」/「分享日志」两个按钮也挪到这里。「分享日志」是不接电脑时唯一的导出路径：
拔掉数据线、只接 Z30 跑一轮，再回来点它，走系统分享发给微信/邮件。

### 高级

- **USB 调试台** —— 连接状态、C1~C9 槽位实况、PTP 指令 Hex 日志、一键诊断、参数形态切换
- **恢复默认设置** —— 只重置本页 9 项，不动预设库和 API Key

## 三、行为随设置改变的地方

| 位置 | 改动 |
|---|---|
| 相册 | `refreshGallery()` 读 `settings.galleryLimit`；页面按钮文案跟着变 |
| 取景 | `startLiveView()` 的帧间隔读 `settings.liveViewIntervalMs`（原来写死 150ms） |
| 刷入 | 模板缺失且开了备份 → 先 `0x90CC` 读回原样存进 `templateCache`；回读校验可关 |
| 拍摄 | 成功后按 `autoSaveCapture` 决定是否调 `saveLastCaptureToPhone()` |
| 日志 | `HexLog.hexDumpEnabled` / `fileLoggingEnabled` 全局开关，改完立刻生效 |

## 四、修掉的两个小问题

1. **设置流覆盖用户操作**：原来 `settings.collect` 每次都把 `targetSlotIndex` 写回去，
   用户在界面上临时改的槽位会被下一帧覆盖。现在只在首次读到设置时应用一次。
2. **日志体积**：`formatEntry` 以前无条件 dump Hex，一帧取景 20KB 就是 1250 行。
   现在受「日志包含 Hex 字节」控制，关掉后日志只剩标题行。

## 六、测试顺序建议

1. 装上后打开 App → 顶栏右上角齿轮 → 设置页应能正常滚到底
2. 改「相册读取张数」为 50 → 回相册页，按钮文案变「刷新最近 50 张」
3. 改「取景帧率」为「省电 3fps」→ 连相机开取景，画面应该更卡但更省电
4. 关「日志包含 Hex 字节」→ 跑一轮取景 → 导出日志，文件应该只有几十 KB
5. 设置 → 高级 → USB 调试台 → 能进，左上返回能退出
6. 「恢复默认设置」→ 回设置页，9 项应回到默认值

## 七、仍未验证 / 已知限制

- `0x500E`（曝光程序）、`0x500D`/`0xD100`（快门）在 Z30 上是**只读属性**（v1.6.4 已用
  `0x1014` 描述符在真机确认），档位与快门只能物理转盘，App 只做显示。
- `0x9207` 拍摄链路仍无真机成功样本（v1.6.3 那份日志里一次 `0x9207` 都没有）。
  如果按快门后「刚拍的这一张」还是空，请用「从机身取最新」按钮兜底，并把日志发回来。
- 200 套内置预设里，美食/夜景两类共 24 套是从真实曲线派生的（带「派生」标签），
  其余 176 套来自 nikonpc.com 的真实 NCP 配方。
